# 📚 Projet de Gestion d’une Bibliothèque

## 🧩 Description
Ce projet a été réalisé dans le cadre d’un TP de Java + PL/SQL.  
Il permet de gérer les livres, les adhérents et les emprunts dans une bibliothèque.

## ⚙️ Technologies utilisées
- Java (JDBC)
- Oracle PL/SQL
- JavaFX (Interface graphique)

## 🗂️ Structure du projet
- `src/main/java` → code source Java  
- `src/plsql` → scripts SQL/PLSQL  
- `docs` → rapport, diagrammes, documentation  

## 🚀 Exécution
1. Créez la base de données Oracle à l’aide des scripts dans `src/plsql/`.
2. Configurez la connexion dans `database.properties`.
3. Exécutez la classe `Main.java`.

## 👥 Équipe
- Personne 1 – Interface & Design JavaFX  
- Personne 2 – Base de données PL/SQL  
- Personne 3 – DAO & Connexion JDBC  
- Personne 4 – Rapport & Documentation
